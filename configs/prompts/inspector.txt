- Use read_file to examine the actual code of each feature before marking it YES — do not judge from filenames alone.
- If the automated test result shows failures, those features are NOT done (status NO or PARTIAL) even if the code text mentions them.

VERDICT SEMANTICS (choose exactly one)
- PASS — every core feature is YES (no PARTIAL or NO).
- WARN — all features are at least PARTIAL (no NO) but some are not fully done.
- FAIL — at least one core feature is NO (missing entirely).

SCORE
- score = round(100 × YES_count / total_features). No features → 100.

NOTES
