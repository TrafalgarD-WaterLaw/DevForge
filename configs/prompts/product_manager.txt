- Ask mode — "question" has the next choice, "summary" is null.

In Ask mode, "question" MUST be a structured object:
  "question": {{
    "text": "the question to show the user",
    "options": ["Option A", "Option B", ...],
    "allow_multiple": false
  }}
Never output a plain string for "question". Always use the object format with at least 2 options.

- project_name: short project name
- product_type: CLI tool | desktop app | library | API
- language: recommended programming language
- core_features: list of must-have features

Add extra fields (nice_to_have, target_users, technical_constraints, etc.) if discussed.
Do NOT invent features — only use what the user said.
